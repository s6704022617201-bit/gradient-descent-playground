Gradient descent คืออะไร

เป็นวิธีหา “จุดต่ำสุด” ของฟังก์ชัน โดยไม่ต้องแก้สมการ — แค่ยืนอยู่ตรงไหนสักที่ แล้วเดินลงตามความชันทีละก้าว ทำซ้ำไปเรื่อย ๆ ก้าวแต่ละก้าวคำนวณจากสูตรนี้

x ← x − lr · f′(x)

f′(x) คือความชัน ณ จุดที่ยืนอยู่ (เส้นสีเขียวในกราฟ) ส่วน lr คือ learning rate ที่บอกว่าจะก้าวยาวแค่ไหน — ตัวนี้แหละที่เป็นหัวใจ

วิธีใช้

  • เลือกฟังก์ชัน แล้วปรับ learning rate ด้วยแถบเลื่อนหรือปุ่ม preset
  • กด Step เพื่อเดินทีละก้าว หรือ Run ให้เดินเองอัตโนมัติ
  • คลิกหรือลากบนกราฟ เพื่อย้ายจุดเริ่มต้นไปที่อื่น
  • คีย์ลัด: ← → เลื่อนจุดเริ่มต้น · Space เดิน 1 ก้าว · R เริ่มใหม่
💡 ลองกดปุ่ม “1.05 ใหญ่ไป” แล้วกด Run ดู — ลูกบอลจะไม่ไหลลง แต่จะกระเด้งออกไกลขึ้นเรื่อย ๆ จนหลุดจอ นี่ไม่ใช่บั๊ก แต่คือสิ่งที่เกิดขึ้นจริงเมื่อ learning rate ใหญ่เกินไป เรียกว่า diverge (ลู่ออก) แล้วลองเทียบกับ “0.01 เล็กไป” ที่ถูกต้องแต่ช้ามากจนน่าหงุดหงิด

ลองสังเกตดู

  • ฟังก์ชัน x⁴ − 3x² + 1 มีจุดต่ำสุด 2 จุด — เริ่มจากคนละฝั่งจะได้คำตอบคนละอัน
  • ฟังก์ชัน x² + 3·sin(2x) ขรุขระ ติด local minimum ง่ายมาก
  • ยิ่งใกล้จุดต่ำสุด ความชันยิ่งน้อย ก้าวก็ยิ่งสั้นลงเอง โดยไม่ต้องสั่ง
