วิธีใช้

Gradient descent เดินตามสูตร (x, y) ← (x, y) − lr · ∇f(x, y) คือก้าวสวนทางกับ gradient เสมอ ในภาพ แกน x กับ y วางราบบนพื้น ส่วนความสูงคือค่า f(x, y) — ยิ่งน้ำเงินเข้มยิ่งต่ำ ลูกบอลส้มคือตำแหน่งปัจจุบัน ลูกศรคือทิศที่กำลังจะก้าวไป (gradient ยิ่งใหญ่ลูกศรยิ่งยาว แต่ยาวถึงระดับหนึ่งแล้วจะหยุด) เม็ดสีส้มคือทางที่เดินผ่านมาแล้ว เม็ดห่างกัน = ก้าวยาว เม็ดถี่ = ก้าวสั้น

วงแหวนสีขาวบนผิวคือ contour (level set) — ทุกจุดบนวงเดียวกันมีค่า f เท่ากัน ข้อสังเกตสำคัญ: gradient ตั้งฉากกับ contour เสมอ — ลากกล้องมามองจากด้านบนจะเห็นลูกศรตัดวงแหวนเป็นมุมฉากชัดที่สุด (มุมเอียงปกติจะดูไม่เป็น 90° เพราะเป็นภาพ perspective)

  • ลอง 3 ปุ่มใต้แถบ learning rate กับฟังก์ชันเดียวกัน: เล็กไป = ใช้ steps เยอะ · กำลังดี = converge ถึง minimum (ถ้าฟังก์ชันนั้นมี) · ใหญ่ไป = เหวี่ยงข้ามจุดต่ำสุดไปมาแรงขึ้นเรื่อย ๆ จนหลุดออกนอกกรอบ
  • Bowl มี global minimum จุดเดียว เริ่มจุดไหนก็ถึง ถ้า learning rate ไม่ใหญ่เกินไป · Saddle ไม่มี minimum เลย จุดเริ่มต้นมาตรฐาน (0.5, 0) วางไว้บนเส้น y = 0 พอดี กด Run แล้วจะเห็นลูกบอลเดินเข้าหา saddle point ก่อน แล้วถูกสะกิดออกไปไถลลง −∞ · Himmelblau มี 4 global minima ที่ต่ำเท่ากัน (f = 0) จุดเริ่มต้นต่างกันจะไหลลงคนละ basin และยังมี local maximum อีก 1 จุดตรงกลาง
