วิธีใช้

Gradient descent เดินลงเขาทีละก้าวด้วยสูตร x ← x − lr · f'(x) — ความชัน f'(x) บอกทิศ ส่วน learning rate บอกว่าก้าวยาวแค่ไหน

  • ลากบนกราฟ เพื่อย้ายจุดเริ่มต้น
  • Step เดินทีละก้าว / Run เดินต่อเนื่อง / Reset เริ่มใหม่
  • ลูกศร ซ้าย ขวา ขยับจุดเริ่มต้น, Spacebar = Step, R = Reset
  • เส้นเขียวคือ เส้นสัมผัส ยิ่งชันแปลว่า gradient ยิ่งแรง ก้าวถัดไปยิ่งไกล
