# Gradient Descent Playground

เครื่องมือแสดงภาพการทำงานของ Gradient Descent แบบ 1 มิติ ให้เห็นว่าลูกบอลไหลลงไปหาจุดต่ำสุดของฟังก์ชันอย่างไร

🔗 **Demo:** _(ใส่ลิงก์ GitHub Pages ตรงนี้)_

## แอปนี้ทำอะไร

แอปนี้จำลองอัลกอริทึม Gradient Descent บนฟังก์ชัน 1 ตัวแปร โดยแสดงเป็นกราฟและลูกบอลที่ค่อย ๆ ไหลลงตามความชันของฟังก์ชันในแต่ละสเต็ป ผู้ใช้เลือกฟังก์ชันได้ 3 แบบ ปรับค่า learning rate (α) เองหรือกดปุ่ม preset เพื่อดูว่า α เล็กเกินไปจะลู่เข้าช้า α พอดีจะลู่เข้าเร็วและนิ่ง ส่วน α ใหญ่เกินไปจะทำให้ค่าลูกบอลแกว่งและลู่ออกจากจุดต่ำสุด เหมาะสำหรับสร้างความเข้าใจโดยสัญชาตญาณ (intuition) ก่อนไปเจอ Gradient Descent เวอร์ชันหลายมิติในวิชาที่สูงขึ้น

## วิธีใช้

- เลือกฟังก์ชันที่ต้องการทดลองจาก dropdown (มี 3 แบบให้เลือก)
- ปรับค่า learning rate ด้วย slider
- กดปุ่ม preset เพื่อลองค่า learning rate สำเร็จรูป (เล็กไป / กำลังดี / ใหญ่ไป) แล้วดูผลต่างของการลู่เข้า-ลู่ออก
- กดปุ่ม **Step** เพื่อขยับลูกบอลทีละสเต็ป, **Run** เพื่อรันต่อเนื่องอัตโนมัติ, **Reset** เพื่อเริ่มใหม่
- คลิกหรือลากบนกราฟเพื่อย้ายจุดเริ่มต้น (starting point) ไปยังตำแหน่งที่ต้องการ
- ใช้คีย์บอร์ดควบคุมได้เช่นกัน: ลูกศรซ้าย/ขวา ขยับจุดเริ่มต้น, **Space** สำหรับ Step/Run, **R** สำหรับ Reset

## คณิตศาสตร์เบื้องหลัง

Gradient Descent อัปเดตค่า x ในแต่ละสเต็ปด้วยสูตร

```
x ← x − α · f'(x)
```

โดยที่ `α` คือ learning rate และ `f'(x)` คืออนุพันธ์ (ความชัน) ของฟังก์ชัน ณ ตำแหน่ง x ปัจจุบัน ไอเดียคือขยับ x ไปในทิศตรงข้ามกับความชัน ทีละนิดตามขนาดของ α เพื่อค่อย ๆ ไล่ลงไปยังจุดที่ฟังก์ชันมีค่าต่ำที่สุด

ถ้า α เล็กเกินไป ลูกบอลจะขยับทีละนิดมาก ทำให้ลู่เข้าช้า แต่ถ้า α ใหญ่เกินไป การขยับแต่ละสเต็ปจะ "แกว่ง" ข้ามจุดต่ำสุดไปมาจนค่าฟังก์ชันเพิ่มขึ้นเรื่อย ๆ แทนที่จะลดลง เรียกว่า **ลู่ออก (diverge)** เงื่อนไขคร่าว ๆ ที่ทำให้ยังลู่เข้าได้ (แถวใกล้จุดต่ำสุด ซึ่งฟังก์ชันประมาณได้ด้วยพาราโบลา) คือ

```
α < 2 / f''(x)
```

โดย `f''(x)` คืออนุพันธ์อันดับสอง (ความโค้ง) ของฟังก์ชันแถวจุดต่ำสุดนั้น ยิ่งฟังก์ชันโค้งชัน (f'' มาก) ยิ่งต้องใช้ α เล็กลง ไม่งั้นจะแกว่งจนลู่ออก

ฟังก์ชันทั้ง 3 แบบในแอปนี้และอนุพันธ์ของมัน:

| ฟังก์ชัน f(x) | อนุพันธ์อันดับ 1 f'(x) | อนุพันธ์อันดับ 2 f''(x) | ลักษณะ |
|---|---|---|---|
| `x²` | `2x` | `2` | มีจุดต่ำสุดเดียว รูปถ้วยเรียบ ๆ |
| `x⁴ − 3x² + 1` | `4x³ − 6x` | `12x² − 6` | มีจุดต่ำสุดสองจุด (local minima) ขึ้นอยู่กับจุดเริ่มต้นว่าจะลงหลุมไหน |
| `x² + 3·sin(2x)` | `2x + 6·cos(2x)` | `4x − 12·sin(2x)` | ขรุขระ มีหลุมตื้น ๆ แทรกอยู่ ลูกบอลอาจติดอยู่ในหลุมตื้นแทนที่จะไปถึงจุดต่ำสุดจริง |

## รันในเครื่อง

## Deploy บน GitHub Pages

1. Push โค้ดขึ้น repository บน GitHub (branch `main`)
2. ไปที่ **Settings → Pages**
3. ในช่อง **Source** เลือก **Deploy from a branch**
4. เลือก branch `main` และโฟลเดอร์ `/ (root)`
5. กด **Save**
6. รอสักครู่ ลิงก์เว็บไซต์จะขึ้นที่ด้านบนของหน้า Pages — นำลิงก์นั้นมาใส่ในช่อง Demo ด้านบนของไฟล์นี้
