# Gradient Descent Playground

เครื่องมือแสดงภาพการทำงานของ Gradient Descent บนพื้นผิว `f(x, y)` แบบ 3 มิติ หมุนดูได้รอบด้าน
ให้เห็นว่าลูกบอลไหลลงไปหา minimum อย่างไร และ learning rate ส่งผลต่อการลู่เข้าอย่างไร

🔗 **Demo:** https://s6704022617201-bit.github.io/gradient-descent-playground/

## แอปนี้ทำอะไร

จำลอง Gradient Descent บนฟังก์ชัน 2 ตัวแปร ซึ่งใกล้กับที่ใช้จริงใน machine learning มากกว่าเวอร์ชัน
ตัวแปรเดียว เพราะอนุพันธ์กลายเป็น **gradient vector** `∇f = (∂f/∂x, ∂f/∂y)` และการอัปเดตกลายเป็น

```
(x, y) ← (x, y) − lr · ∇f(x, y)
```

ผู้ใช้เลือกพื้นผิวได้ 3 แบบ ปรับ learning rate ด้วย slider แบบ log scale หรือกดปุ่ม preset
แล้วดูว่าลูกบอลลงถึง minimum, เดินช้าจนชนเพดาน หรือกระโดดแรงจนหลุดออกนอกกรอบ

พื้นผิวถูกระบายด้วยสีฟ้าเฉดเดียวไล่เข้มตามความลึก (ยิ่งเข้มยิ่งต่ำ) และมี **เส้น contour**
(level set) วาดทับ ซึ่งทำให้เห็นข้อเท็จจริงสำคัญข้อหนึ่ง: **gradient ตั้งฉากกับ contour เสมอ**

## พื้นผิว 3 แบบ

| พื้นผิว | สูตร | ∂f/∂x | ∂f/∂y | สอนอะไร |
|---|---|---|---|---|
| **Bowl** | `x² + y²` | `2x` | `2y` | convex — ทุกจุดเริ่มต้นลงถึง global minimum จุดเดียวกันที่ (0, 0) |
| **Saddle** | `x² − y²` | `2x` | `−2y` | **ไม่มี minimum เลย** จุด (0, 0) มี `∇f = 0` แต่เป็น saddle point ไม่ใช่คำตอบ |
| **Himmelblau** | `(x²+y−11)² + (x+y²−7)²` | `4x(x²+y−11) + 2(x+y²−7)` | `2(x²+y−11) + 4y(x+y²−7)` | มี global minima 4 จุด ค่า `f = 0` เท่ากันหมด จุดเริ่มต้นต่างกันนิดเดียวก็ไหลลงคนละ basin |

จุดต่ำสุดทั้งสี่ของ Himmelblau: `(3, 2)`, `(−2.805118, 3.131312)`, `(−3.779310, −3.283186)`,
`(3.584428, −1.848126)` และมี local maximum อีก 1 จุดที่ `(−0.270845, −0.923039)`

## วิธีใช้

- เลือกพื้นผิวจากการ์ด 3 ใบด้านบน
- ปรับ learning rate ด้วย slider (log scale) หรือกดปุ่ม preset — ค่า preset เปลี่ยนตามพื้นผิว
  เพราะความชันของแต่ละฟังก์ชันต่างกันมาก (Himmelblau ต้องใช้ค่าเล็กกว่า Bowl ราว 10 เท่า)
- **Step** เดินทีละก้าว · **Run** เดินต่อเนื่อง · **Reset** เริ่มใหม่
- ลากบนภาพเพื่อหมุนกล้อง สกรอลล์หรือหยิกสองนิ้วเพื่อซูม แตะ (ไม่ลาก) บนผิวเพื่อวางจุดเริ่มต้นใหม่
- คีย์บอร์ด: `Space` เดิน 1 ก้าว · `Enter` Run/Pause · `R` Reset · `←↑→↓` เลื่อนจุดเริ่มต้น

## เงื่อนไขความเสถียร

แถวใกล้ minimum ฟังก์ชันประมาณได้ด้วยพาราโบลา เงื่อนไขคร่าว ๆ ที่ยังลู่เข้าคือ

```
lr < 2 / λmax
```

โดย `λmax` คือ eigenvalue ที่ใหญ่ที่สุดของ Hessian ณ จุดนั้น สำหรับ Bowl ที่ Hessian เป็น `2I`
ได้ `lr < 1` ส่วน Himmelblau แถวจุด `(3, 2)` มี `λmax ≈ 82` จึงต้องใช้ `lr < 0.024` — ต่างกันเกิน 40 เท่า
นี่คือเหตุผลที่ค่า preset ต้องเปลี่ยนตามพื้นผิว
